\item $\sin\alpha = \sin[(\alpha + \beta) - \beta] = \sin(\alpha + \beta)\cos\beta - \cos(\alpha + \beta)\sin\beta$

\item Expand both sides:

  $(\cos\alpha\cos\beta - \sin\alpha\sin\beta)(\sin\gamma\cos\delta + \cos\gamma\sin\delta) = (\cos\alpha\cos\beta +
  \sin\alpha\sin\beta)(\sin\gamma\cos\delta - \cos\gamma\sin\delta)$

  After cancellation, $2\cos\alpha\cos\beta\cos\gamma\sin\delta = 2\sin\alpha\sin\beta\sin\gamma\cos\delta$

  Dividing by $\sin\alpha\sin\beta\sin\gamma\sin\delta,$ $\cot\alpha\cot\beta\cot\gamma = \cot\delta$

\item Let $t = \tan\beta.$ $\tan(\alpha - \beta) = \frac{nt - t}{1 + nt^2} = \frac{(n - 1)t}{1 + nt^2}$

  1)^2}{4n}$

\item With $n = 3$ in the previous problem, $\tan(\alpha - \beta) = \frac{2t}{1 + 3t^2} \leq \frac{1}{\sqrt{3}}$

  Since $0 < \alpha - \beta < \frac{\pi}{2},$ $\alpha - \beta \leq \frac{\pi}{6}$

  Equality when $3t^2 = 1,$ i.e. $\beta = \frac{\pi}{6}, \alpha = \frac{\pi}{3}.$ Greatest value is $\frac{\pi}{6}$

\item L.H.S. $= \cos^2\alpha + \cos(\alpha + \beta)[\cos(\alpha + \beta) - 2\cos\alpha\cos\beta]$
