\item $y = -2\cos\left(\frac{x}{2} + \frac{\pi}{4}\right) - 1 = -2\cos\frac{1}{2}\left(x + \frac{\pi}{2}\right) - 1$

  Amplitude $= |-2| = 2,$ period $= \frac{2\pi}{1/2} = 4\pi,$ phase shift $= \frac{\pi}{2}$ to the left.

  $-1\leq\cos\left(\frac{x}{2} + \frac{\pi}{4}\right)\leq 1 \Rightarrow -3\leq y\leq 1.$ So range is $[-3, 1].$

  \frac{\pi}{4} = 2n\pi \Rightarrow x = 4n\pi - \frac{\pi}{2},$ where $n\in I.$
